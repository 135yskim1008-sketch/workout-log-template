# 운동 기록

부위별로 운동을 골라 무게·세트·횟수를 적으면, 표로 정리하고 다음 운동 방향을 3줄로 알려주는 운동 기록 앱입니다. 설치할 프로그램 없이 파일 하나(`index.html`)로 돌아갑니다.

## 기능

- **운동 고르기**: 가슴·등·하체·어깨·이두·삼두·복근·러닝 부위별(색 구분) 운동 목록에서 눌러서 선택
- 무게·세트·횟수를 직접 적거나 −／＋로 조절, 줄마다 **웜업 / 본세트 / 쿨다운** 구분, 운동별 메모
- 글로 적어도 됨: `스쿼트 60x8, 80x8웜업` / `100x8,6,5 - 2세트부터 자세 무너짐` / `러닝 3km 20분`
- 코멘트 3줄: ① 지난 기록과 비교(신기록·정체·하락) ② 최근 7일 부위별 세트 수(웜업 제외) ③ 다음 운동에서 바꿀 무게·세트
- 지난 기록 보기, CSV 내려받기·불러오기

## 쓰는 법

- **컴퓨터**: `index.html`을 두 번 클릭하면 인터넷 창으로 열립니다.
- **핸드폰에 앱처럼 설치**: 웹 주소로 올린 뒤(예: GitHub Pages) 핸드폰으로 그 주소를 엽니다.
  - 안드로이드(크롬): 메뉴 ⋮ → "홈 화면에 추가" / "앱 설치"
  - 아이폰(사파리): 공유 버튼 → "홈 화면에 추가"
  - 한 번 열고 나면 인터넷이 없어도 열립니다.

## 구글 시트 자동 연동 (선택)

핸드폰과 노트북 기록을 **내 구글 시트 하나**에 모아 자동으로 맞출 수 있어요. 앱의 "☁️ 구글 시트 자동 연동" 칸에 단계별 안내와 [코드 복사] 버튼이 있어요(처음 한 번, 약 5분).

1. 새 구글 시트 → 확장 프로그램 → Apps Script → 앱에서 복사한 코드 붙여넣기 → 저장
2. 배포 → 새 배포 → 웹 앱 → 액세스: 모든 사용자 → 배포 → 권한 허용
3. 웹 앱 URL을 앱에 붙여넣고 [연결]
4. 다른 기기는 "다른 기기 연결 코드"를 붙여넣으면 끝

기록은 내 구글 계정의 시트에만 저장되고, 연결 코드는 비밀번호와 같으니 남에게 보내지 마세요. (`구글시트연동.gs`는 그 코드의 사본이에요)

## 개인정보

- 이 원본에는 **누구의 운동 기록도, 개인 정보도 들어 있지 않습니다.**
- 적은 기록은 각자의 **기기 브라우저 안에만** 저장되고, 어디로도 전송되지 않습니다. 그래서 다른 사람과 기록이 섞이지 않습니다.
- 같은 이유로 핸드폰과 컴퓨터의 기록은 자동으로 합쳐지지 않습니다(CSV 내려받기·불러오기로 옮길 수 있음).
